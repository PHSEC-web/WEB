# PSEC 档案库操作指南

本指南对应统一记录模型。每一条研究内容都是一条 **Record（记录）**；每次提交、审核或补充都会形成一个不可覆盖的 **Revision（版本）**。

## 成员：从想法到成果

### 1. 登录并提交

打开 **Submit an idea**，填写三个必填项：**Submitter Name、Experiment / project title、One-sentence summary**。系统会要求使用学校邮箱验证码登录，以便将记录绑定到提交者。其余研究字段和附件可以先留空，日后继续补充。

提交后，记录进入 `pending`（待审核）状态，并出现在 **My Records** 页面，而不会出现在公开图书馆。

### 2. 查看审核状态

打开导航栏中的 **My Records**。这里会显示你自己创建的记录、当前审核状态、管理员意见和版本号。

| 状态 | 含义 | 成员下一步 |
|---|---|---|
| `pending` | 等待管理员审核 | 无需重复提交；可等待审核结论 |
| `needs_revision` | 需要补充或修订 | 根据管理员评语补充内容后重新提交（当前版本仍会保留） |
| `published` | 已公开归档 | 可以继续追加结果、反思和文件 |
| `rejected` | 本次不进入公开档案 | 可将想法改写为新的独立项目再提交 |

### 3. 追加成果和报告

在 **My Records** 中选择 **Add results**。填写结果与结论；可选填局限与反思、下一研究问题、伦理或同意说明，并上传报告、照片或数据。

只要保存了结果，项目生命周期会自动进入 `completed`。每次追加都会生成新的版本，旧版本不会被覆盖。

### 4. 附件可见性

| 文件类型 | 默认可见性 | 适合上传的内容 |
|---|---|---|
| 照片、报告、协议 | public | 脱敏后的实验照片、公开报告、研究方案 |
| 数据 | members | 原始表格、含有限制性材料的数据文件 |

单文件上限为 **8 MB**；一次成果追加最多 8 个文件。上传任何与参与者有关的材料前，应完成脱敏、同意、隐私和学校审查。

## 公开访问者：阅读与导出

公开记录在学科图书馆中可进入 **Open shareable record**。详情页显示研究内容、结果区块、公开附件和版本时间线。

点击 **Evidence pack** 可生成适合打印的页面，再用浏览器的 **Print / Save PDF** 保存。证据包包括记录全文、公开附件清单、版本时间线、伦理说明和生成时间。

`members` 附件不会出现在公开清单中；直接访问此类附件会返回 404。

## 管理员：审核与发布

1. 从 **Admin Access** 进入管理员队列并输入授权密码。
2. 打开待审核记录，确认正文、上传文件、学科、生命周期和可见性。
3. 使用默认的 **Approve** 动作发布；发布将保留原始字段、附件和完整版本链，不复制到第二张内容表。
4. 如需修改，使用追加式管理员修订；不要用删除覆盖历史。
5. 对明显错误或需撤下的记录使用隐藏操作。隐藏记录不出现在公开列表，但仍保留审计链。

## 术语约定

| 术语 | 正确含义 |
|---|---|
| 记录（Record） | 一条项目或学术参考档案 |
| 版本（Revision） | 该记录某个时点的不可变快照 |
| 追加（Append） | 写入一个新版本，不覆盖旧内容 |
| 生命周期（Lifecycle） | idea、design、in_progress、completed |
| 审核状态（Status） | pending、needs_revision、published、rejected、hidden |
| 证据包（Evidence Pack） | 记录正文、时间线、附件清单和伦理说明的可打印集合 |

> 任何“编辑”都应理解为“追加版本”。这确保研究过程可追溯，也让未来成员能够看到结论是如何形成的。
